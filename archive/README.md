# Archive — retired prototype

These three files are the **retired first version** of this project: a
client-only, no-backend, single-file demo (`ajd.html`, state in
`localStorage`) plus the standing development process that was built around
it (`ITERATE.md`, `ITERATION_LOG.md`).

On 2026-10-11 the project was rebuilt from scratch as a real Express/SQLite
backend under [`app/`](../app) ("AJD Design Manager" — see the top-level
[CLAUDE.md](../CLAUDE.md)), which replaced this prototype entirely. These
files are kept for reference only — they are not run, not linked from the
live app, and not maintained. Do not resume `ITERATE.md`'s loop or add new
entries to `ITERATION_LOG.md`; both describe a process that was scoped to
`ajd.html` and ended when that file was retired.
